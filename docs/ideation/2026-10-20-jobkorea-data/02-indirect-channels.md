1. 잡코리아 공고를 잡코리아 밖에서 정당하게 받는 통로 9개를 찾았지만, 개인이 매일 자동으로 받을 수 있다고 확인된 새 통로는 0개다. [S1~S22, 확인 2026-10-20]
2. 가장 유망한 새 단서는 고용24(구 워크넷) 채용정보의 '정보제공처=잡코리아' 연계다. 2011년 협약과 고용24 안내(검색 요약)에서 민간 포털 연계가 확인되지만, 전량인지, 어떤 API로 받을 수 있는지는 확인 못 함이다. [S1·S2]
3. 잡코리아와 사람인·공채속보의 공고 중복률을 직접 보여주는 공개 통계나 연구는 찾지 못했다(확인 못 함). 그래서 사람인 키 발급 후 실행할 커버리지 실험 설계를 9절에 썼다. [9절]
4. 네이버·다음·통신사·카드사 제휴에서는 잡코리아 공고를 싣는다는 근거를 못 찾았고, 웍스피어(잡코리아)의 제휴 문의 유형에도 데이터·API가 없다. 구글 채용정보 검색은 2018년 제휴 기사만 있다. [S7·S8·S14·S15]
5. 결론: 새 주력 소스는 없고, 현실적인 다음 행동은 사람인 커버리지 실험(호출 약 30~50회)과 고용24 필터 건수를 이용한 1회성 분모 대조다. 둘 다 사용자 결정이 필요하다. [8~9절, 추정]

## 2. I-1 고용24 채용정보의 민간 포털 연계

- **통로:** 고용24(구 워크넷) 채용정보 통합 검색. 상세검색의 '정보제공처'에서 잡코리아·사람인·인크루트 등을 고를 수 있다.
- **잡코리아 공고와 겹치는 근거:**
  - 2011-03-16 워크넷–민간 포털 협약에 잡코리아가 사람인·커리어와 함께 포함됐다. 기사는 3곳의 정보를 "우선 제공"한다고만 하고, 건수나 전량 여부는 쓰지 않았다. [S1, 직접 열람]
  - 검색 요약은 고용24 안내에 "민간취업포털 24개 기관의 구인정보도 워크넷에서 찾아볼 수 있다"는 문구가 있다고 전하며, 상세검색 정보제공처 목록에 잡코리아가 있다고 한다. 어느 페이지의 문구인지, 24개 목록이 무엇인지는 직접 확인 못 함이다. [S2, 검색 요약]
  - 한 공고 상세에서 정보제공처가 사람인으로 표시되고 원 사이트 링크가 나온다는 요약도 있다. [S2, 검색 요약]
  - 2026-05-14 인천일자리플랫폼 기사는 "기존 포털은 고용24 연계에 그쳤다"고 쓴다. 즉 지자체 포털이 고용24 연계와 민간 포털 직접 연계를 구분한다. [S3, 직접 열람]
- **개인 가능성:** 웹 화면은 누구나 열람할 수 있다(추정). 자동 수신은 낮다. mvp-design-review 0절이 "고용24 채용정보 목록·상세는 개인 불가"로 판정했고, 공채속보 개인 API가 이런 연계 공고를 포함하는지는 확인 못 함이다.
- **완전성 확인 수단:** 검색 결과 건수가 화면에 표시된다는 요약이 있다(직접 확인 못 함). '정보제공처=잡코리아'로 건수를 보고, 같은 조건의 잡코리아 '전체 (N건)'(08 스파이크 샘플은 109건)과 비교하면 **연계가 전량에 가까운지** 1회성으로 잴 수 있다. 직종·지역 분류가 서로 달라 조건을 완전히 맞추지 못하므로 어디까지나 추정이다.
- **위험:**
  - 연계 범위가 일부이거나 지연될 수 있다(2011년 "우선 제공" 표현뿐, 확인 못 함).
  - 연계 공고는 원 사이트로 넘어가는 링크일 수 있어 모집 단위 정보가 얕다(추정).
  - 사용자의 일일 수동 열람은 이미 기각된 체크리스트와 같은 비용 문제가 있다. 그러므로 **1회성 측정**으로만 제안한다.
  - 자동 수집은 불변식상 금지이고, 고용24 이용약관 확인은 이 조사에서 하지 못했다(확인 못 함).
- **근거:** S1(직접), S2(검색 요약), S3(직접), 06(Open API 개인 불가) 및 mvp-design-review 0절.

## 3. I-2 사람인 API: 같은 기업의 동시 게시

- **잡코리아 공고와 겹치는 근거:** 기업은 여러 채널에 공고를 올린다는 사실이 이 회의의 전제인데, 한국 채용 포털 간 중복률 통계는 찾지 못했다(확인 못 함, 7절). 구직자 설문(포털 이용 이유)은 있으나 기업의 복수 게시율이 아니다.
- **개인 가능성:** 사용자가 신청 예정(P-0). 승인 여부는 미확인이다.
- **완전성 확인 수단:** 사람인 응답에 `total`(검색 결과 총수)과 `count`(최대 110), `start`(페이지 번호)가 있어 쿼리별로 끝까지 받았는지 확인된다. [S10, 직접 열람] 잡코리아 쪽 분모는 이 통로가 주지 않는다. 9절 실험이 분모를 만든다.
- **위험:** 사람인에 없는 잡코리아 단독 공고가 얼마인지 모른다. 일일 한도는 가이드 페이지에 수치가 없다(AGENTS.md는 500회로 적음). 공고 저장·표시 조건은 가이드에 없다. 별도 약관을 읽어야 한다(`/guide/rule`은 404).
- **근거:** S10(직접).

## 4. I-3 고용24 공채속보(개인)·인크루트 RSS: 겹침 측정 대상

- **잡코리아 공고와 겹치는 근거:** 공채는 기업이 여러 곳에 게시한다는 것이 일반 통념이지만, 공채속보와 잡코리아의 중복률 근거는 못 찾았다. 추정이다.
- **개인 가능성:** 공채속보 개인 신청은 가능, 발급 미확인(mvp-design-review 0절). 인크루트 RSS는 현행 작동·저장 허락을 확인 못 함(06).
- **완전성 확인 수단:** 공채속보는 쿼리별 마지막 페이지 확인이 가능하다. 인크루트 RSS는 총수와 과거 페이지를 확인 못 함(06).
- **위험:** 이미 확정한 소스이므로 이 회의에서 새 소스로 세지 않는다. 중복이 크면 잡코리아 별도 경로의 필요가 줄어드는 근거가 된다.
- **근거:** 06, mvp-design-review 0절.

## 5. I-4 지자체 일자리 플랫폼·공공데이터

- **통로:**
  - 인천일자리플랫폼(2026-05-14 개설). 잡코리아·사람인 등 민간 채용사이트와 나라일터·잡알리오 등을 통합했고, 올해 등록분 민간 공고 20,609건, 공공 381건이라고 한다. API 등 연동 방식은 기사에 없다. [S3, 직접 열람]
  - 경상북도 김천시 「민간 일자리정보」 공공데이터. 설명이 "워크넷, 사람인, 잡코리아와 연계된 데이터". CSV, XML, JSON, 전체 25,469행, **갱신 주기 연간**(다음 등록 2027-09-01), 이용허락범위 제한 없음. 파일은 로그인 없이 다운로드, 오픈API는 회원가입과 활용신청이 필요하다. [S4, 직접 열람]
  - 영등포구 「우리동네 일자리정보」(2023-11-01). 워크넷·서울시일자리포털과 연동해 "연계된 모든 공공·민간 채용 정보를 실시간 제공"한다고 한다. 민간 포털 이름과 잡코리아 포함 여부는 기사에 없다. [S5, 직접 열람]
  - 서울시 일자리포털 채용 정보 데이터. 공공누리 제1유형, 자동 갱신, 100행. 잡코리아 포함 근거 없음. [S6, 직접 열람]
- **잡코리아 공고와 겹치는 근거:** 김천시 설명과 인천 기사만 명시한다. 둘 다 연계 데이터 안에 잡코리아 공고가 어떤 필드로 구분되는지는 확인 못 함이다.
- **개인 가능성:** 김천 파일은 즉시 다운로드 가능. 인천·영등포의 개인용 API는 확인 못 함. 잡코리아 Open API가 공공기관 우선이라는 안내(S9)와 맞물려, 지자체 포털이 그 이용자일 가능성이 있다(추정).
- **완전성 확인 수단:** 김천은 행 수(25,469)만 있다. 지역 한정이고, 연 1회 갱신이라 매일 신입 공고를 받는 용도에는 맞지 않는다. 인천은 확인 못 함.
- **위험:** 지역 한정(경북 김천, 인천). 데이터 기준일이 오래되면 이미 마감된 공고다. 연계 원본 표시 컬럼이 있는지 확인 못 함. 지원 링크가 잡코리아 원문 URL인지도 확인 못 함.
- **쓸 곳 (제안):** 일일 수신기가 아니라 (a) 연계 데이터에서 잡코리아 공고 비율과 필드 구성을 한 번 보는 표본, (b) 사람인 API와의 사후 중복 측정 표본. 단 지역·시점이 달라 서울 신입 IT에는 일반화하지 못한다(추정).
- **근거:** S3~S6(직접).

- **카카오톡 오픈채팅:** 2026-04-17 기사. 잡코리아가 개발·PM/PO·디자인·마케팅 직무별 오픈채팅을 운영하고 인기 공고를 공유한다. 정식 외부 제휴 설명은 없고 인기 공고만이라 완전성 확인이 불가능하다. [S13, 직접 열람]
- **우리WON글로벌(KLiK):** 외국인 대상 채용 공고를 잡코리아·인크루트·사람인·원티드랩 등에서 모아 보여준다는 2025-06 보도가 검색 요약에 있다. 대상이 외국인 채용이라 이 프로젝트의 신입 IT 범위와 다르다. [S14, 검색 요약]
- **웍스피어 제휴 문의 페이지:** 제휴 유형이 공동 파트너십, 프로모션, 광고·마케팅, 콘텐츠, 채용 서비스, 기타(B2G 협력 포함)다. **데이터·API 제휴 유형은 없다.** 개인이 데이터 제휴를 맺을 창구가 공개돼 있지 않다는 간접 증거다. 문의는 보내지 않았다. [S15, 직접 열람]

### I-6 포털 검색 (네이버·다음·구글)

- **네이버:** 2020-12-18 기사는 통합검색에 채용 컬렉션을 만들어 워크넷·잡플래닛·샵마넷 등과 제휴한다고 쓴다. 잡코리아·사람인은 기사에 없다. 현행 제휴 목록은 확인 못 함. [S7, 직접 열람] 워크넷 연계분이 네이버를 통해 노출될 가능성은 추정일 뿐 근거는 없다. 네이버 검색 API의 저장 제약은 06에서 이미 닫았다.
- **다음(카카오):** 2016-08-24 보도자료. 잡플래닛과 제휴해 '기업명+채용' 검색에 기업 리뷰·연봉·면접 후기를 보여준다. 공고가 아니고 잡코리아는 언급되지 않는다. [S8, 직접 열람]
- **구글 채용정보 검색:** 2018-12 기사(검색 요약)에 11개 제휴 사이트로 잡코리아·인크루트 등이 있고 사람인은 없다. 현재 제휴가 이어지는지는 확인 못 함. 구글 검색 API 경로는 06에서 닫혔고(신규 이용 불가), 화면 자동 수집은 불변식상 금지다. [S16, 검색 요약]
- **판정:** 잡코리아 공고가 포털에 노출될 가능성은 있어도 정당하게 기계적으로 받는 경로가 없다. 수동 대조 외에는 쓸 수 없다.

### I-7 기업 자사 채용 페이지·ATS

- **나인하이어(웍스피어 계열 ATS):** 도움말에 따르면 나인하이어에서 잡코리아 계정을 연동하면 나인하이어에 만든 공고를 잡코리아에 게시·마감할 수 있고(모든 요금제), 제목·본문이 그대로 넘어간다. 나인하이어 안에서 채용 홈페이지를 만들 수 있지만, 같은 공고가 자사 홈페이지에도 자동 게시되는지는 확인 못 함이다. [S17, 검색 요약. 같은 도움말의 다른 문서는 직접 열람했으나 이 내용은 없었음]
- **그리팅:** 원티드(2025-07)·프로그래머스와 연동해 같은 공고를 올린다는 보도가 있다. 사람인·잡코리아와의 직접 연동은 못 찾음. [S18, 검색 요약]
- **개인 가능성:** 기업마다 개별 접근이 필요하고, 공개 피드나 API는 세 서비스 모두 확인 못 함이다. 기업 목록 없이는 완전성을 말할 수 없다.
- **쓸 곳 (제안):** 사용자가 관심 있는 기업 몇 곳의 자사 채용 페이지 주소를 직접 적어 두고, 사람인 API 결과에 없을 때 사용자가 직접 보는 보조 확인. 자동 수집은 금지다.

### I-8 통신사·카드사·은행

- 통신사·카드사와 잡코리아의 채용 공고 제휴는 검색에서 근거를 못 찾았다(확인 못 함). 전용 보도자료 검색은 하지 않았다.
- 은행은 우리은행–잡코리아 KLiK 외국인 구인구직 협약(I-5)뿐이다. [S14, 검색 요약]

### I-9 AI·에이전트 채널

- 잡코리아는 2026-01 웍스피어로 사명을 바꾸고 AI 커리어 에이전트로 전환한다고 발표했다. 외부 AI 서비스(ChatGPT·클로드·MCP 등)와의 공고 연동 발표는 검색에서 확인 못 함이다. [S19, 검색 요약]
- 제휴 창구에 데이터 제휴 유형이 없다는 점(S15)과 합쳐 보면, 가까운 시일에 개인에게 열릴 가능성은 낮다(추정).

## 7. 중복률 공개 통계·연구: 확인 못 함

- 잡코리아와 사람인·공채속보·고용24 사이의 공고 중복률을 직접 보여주는 공개 통계나 학술 연구는 찾지 못했다. 한 보도에서는 플랫폼 관계자가 허위·중복 공고 규모를 별도로 파악한 데이터가 없다고 답했다는 요약이 있다. [S20, 검색 요약]
- 같은 공고가 반복 게시되는 현상 서술, 직업안정법 개정 논의는 있으나 비율이 없다.
- 그래서 중복률은 **추정할 근거가 없고 직접 측정해야 한다.** 9절이 그 측정 설계다.
- 반증이 될 만한 자료로 2011년 워크넷 협약 기사(S1)가 있다. 정부가 민간 포털 정보를 가져와 보여줄 만큼 민간 포털에 공고가 몰려 있다는 맥락이지, 중복률 근거는 아니다.

## 9. 사람인 API로 잡코리아 공고를 얼마나 덮는지 재는 실험 설계

**전제:** 사람인 키가 발급된 뒤에만 실행한다. 이 문서 작성 중에는 사람인 API를 호출하지 않았다. 실제 호출은 AGENTS.md 7번대로 사용자의 명시적 지시가 있을 때만 한다. 응답 픽스처를 저장할 때는 키와 개인정보를 지운다.

### 9-1 질문과 지표

- **Q1:** 잡코리아에 올라온 신입 IT 공고 중 사람인 API 결과에서도 찾을 수 있는 비율(커버리지).
- **Q2:** 사람인에 없는 잡코리아 단독 공고는 어떤 공고인가(기업 규모, 직무, 통합 공고 여부).
- **지표:** 커버리지 = (A 매칭 + 검토 후 확정한 B 매칭) ÷ 잡코리아 기준 표본 수 N. Wilson 95% 구간을 함께 낸다. p=0.5일 때 반폭은 N=40에서 약 ±15%p, N=109에서 약 ±9%p다(정규근사 계산, 추정).

### 9-2 잡코리아 쪽 기준 표본 (새 접근 없이)

| 선택지 | 내용 | 비용·한계 |

### 9-3 사람인 쪽 조회 (실제 호출은 하지 않음)

- 요청: `GET https://oapi.saramin.co.kr/job-search`, `access-key`는 환경변수로 전달. 조건은 잡코리아 쪽과 맞춘다(서울, 신입, IT 직무 4종). `job_type`, `edu_lv`, `loc_cd`, `job_cd` 값의 정확한 코드는 사람인 코드표에서 확인해야 하며 이 조사에서는 확인 못 함이다. [S10]
- 페이지: `count=110`(가이드의 최대값), `start`는 0부터 증가시키며 `total`까지 끝까지 받는다. 헤드헌팅·파견 제외 옵션(`sr`)을 쓸지는 잡코리아 쪽 표본에서 파견을 제외한 것과 맞춰 정한다. `fields`로 게시일·마감일을 추가한다.
- 보완 조회: 첫 조회에 안 잡힌 표본 항목은 `keywords=<회사명>`으로 회사별 재조회한다(최대 40회).
- **호출 예산(추정):** 조건 조회 수 회 + 회사별 재조회 최대 40회 = 약 30~50회. 일일 한도 500회(AGENTS.md)의 10% 이하다. 한도 초과 시 에러 코드 4다.

### 9-4 매칭 규칙 (고유 ID가 없으므로 대체 키)

1. 회사명 정규화: `㈜`, `주식회사`, 공백, 영문 대소문자 통일.
2. 제목 정규화 후 토큰 유사도(예: 자카드)를 계산한다.
3. 등급:
   - **A:** 회사 동일 + 제목 유사도 기준 이상 + 마감일 일치 또는 근접
   - **B:** 회사 동일 + 제목 상이. 같은 기업의 다른 포지션이거나 통합 공고일 수 있어 **사람이 전수 검토**한다(40건 규모면 가능).
   - **C:** 회사 불일치 → 미매칭 후보
4. 유사도 기준과 마감일 허용 오차는 **표본을 보기 전에** 정한다. 이 문서는 값을 정하지 않는다(미정).
5. 통합 공고(예: ㈜아이센스 사례)는 mvp-design-review 0-1절 원칙대로 제목만으로 제외·불일치 처리하지 않고 B로 보낸다.

### 9-5 결과 해석 (제안, 확정 아님)

| 커버리지 | 해석 |
| --- | --- |
| 90% 이상 | 사람인만으로 충분. 잡코리아 별도 경로 우선순위 낮음 |
| 70~90% | 보조 경로(알림 메일, I-1 수동 대조)의 가치가 있음 |
| 70% 미만 | 잡코리아 단독 공고가 많음. 별도 경로 논의 필요 |

임계값은 연구자 제안이며 사용자 승인 사항이다. N이 작아 구간이 넓으므로 한 숫자로 결정하지 않는다.

### 9-6 편향과 한계

- 추천순 1페이지 표본이라 광고(스마트픽 3건은 08 파서가 제외)와 정렬 알고리즘의 영향을 받는다.
- 잡코리아 표본이 사람인 조회보다 먼저 만들어졌다. 그 사이 마감·신규 등록으로 어긋난다. 같은 날 조회가 가장 낫고 어렵다면 어긋남을 표본 한계로 기록한다.
- 사람인 직무 코드와 잡코리아 직무 분류가 서로 달라 "같은 조건"은 근사치다.
- 사람인 API는 사람인 공고만 준다. 사람인에 없고 잡코리아에만 있는 공고가 고용24 연계나 자사 페이지에 있는지는 이 실험이 답하지 못한다.

### 9-7 2차 실험 (선택, 사용자 1회 수동)

- E2: 사람인 미매칭 상위 10건 안팎에 대해, 사용자가 고용24 상세검색에서 회사명으로 한 번 찾아 보고(정보제공처 표시 확인), 있는지 없는지를 표에 적는다. 자동화하지 않는다.
- E3: I-1의 건수 대조. 같은 조건에서 고용24 '정보제공처=잡코리아' 건수 ÷ 잡코리아 '전체 (N건)'. 조건이 완전히 같지 않아 추정이다.
