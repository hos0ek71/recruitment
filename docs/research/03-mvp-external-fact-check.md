# MVP 외부 사실 검증: 채용 API

- 조사일: 2026-10-17. 대상: `공채 모아보기 MVP 설계 문서.md`의 데이터 소스·제약·HEADHUNTING·리스크·미정 사항 및 연결된 수집 전제.
- 공식 공개 문서의 **문서상 계약**을 확인했다. 인증키 신청·로그인·실제 채용 API 호출은 하지 않았으므로, 운영 중 동작이나 승인 가능성을 보증하지 않는다.
- `확인됨`은 공식 근거가 있는 경우, `부분적으로 맞음`은 조건 누락·공식 안내 내부 모순·설계 전제의 과장이 있는 경우다. 명세의 필드 부재는 해당 API 공개 명세에 없다는 의미이며, 공급자의 모든 상품에 없다는 뜻은 아니다.
- 공식 문서만 판정 근거로 사용했다. GitHub 저장소의 구현은 해당 저장소 자체를 1차 출처로 삼았다. 블로그를 근거로 확정한 항목은 없다.

## 설계 반영 필요 사항

1. **고용24를 무조건 확보된 대체 소스로 취급하지 않는다.** 기업회원 전용·심사 조건을 데이터 소스와 승인 리스크에 명시하고, 개인 프로젝트의 실제 이용 자격 확인을 선행 과제로 추가한다. 사람인 개인 신청 허용·승인 소요기간도 계속 미정으로 둔다.
2. 고용24 신청 안내를 현재 공식 포털로 연결하고 목록/상세 엔드포인트를 분리한다. XML 파서·원본 보존 방식 및 상세 호출 예산을 설계한다. 포털의 LINK형 메타정보를 data.go.kr 인증키로 직접 호출 가능한 일반 게이트웨이 API와 혼동하지 않는다.
3. 고용24 사원수는 상세 `totPsncnt`, 담당업무는 상세 `jobCont`에서 받는다고 명시한다. 필드 존재와 값의 완전성은 별개이므로 누락 시 기존 '확인 필요' 규칙을 유지한다. 사람인 원문 담당업무·사원수 부재 설명은 유지한다.
4. 수집 계약에 사람인 `start=0`, `count<=110`, 고용24 `startPage=1..1000`, `display<=100`을 적는다. 페이지 상한·호출 예산에 걸리면 partial로 남기고, 승인된 범위를 보존하는 쿼리 분할 방안을 검토한다. 사람인 `start×count` 무제한은 가정하지 않는다.
5. 증분 수집은 소스별로 구분한다. 사람인은 등록시각 범위와 수정시각 범위를 구별하고, 고용24는 상대 기간 검색에 중첩 구간·ID 중복 제거를 적용하는 방안을 검토한다. '끝까지 조회'와 '실행 사이 이미 마감된 공고까지 빠짐없이 확보'를 구분한다.
6. HEADHUNTING 행에 `sr=directhire`를 적되, 공급자가 미리 제외한 공고는 개별 탈락 사유를 남길 수 없다고 명시한다. 수집 범위 제외와 수집 후 필터 탈락의 통계를 구분하는 제품 결정을 요구한다. 반환되지 않은 공고를 탈락 기록으로 만들어서는 안 된다.
7. 사람인 일일 초과 `code=4`를 오류 매핑에 명시한다. 고용24 일일 수치는 확인 전 설정값으로 확정하지 않는다. 사람인 400회 중단은 공식 한도가 아니라 자체 예산임을 구분한다.
8. `infoSvc`는 중복 병합의 확정 식별자가 아니므로 출처 메타데이터로만 해석한다. 목록 응답의 `busino`와 유사도 등을 쓰더라도 동일성 판단은 별도 설계 검증이 필요하다.
9. 잡코리아는 100/500/신입 무제한이 함께 기재된 공식 문서의 모순을 미정 사항에 남긴다. 원티드는 사업자등록번호 등 필수 입력과 권한별 심사를 미정 사항에 추가하고 개인 예외는 보장하지 않는다.
10. 참고 저장소는 현재 브라우저 기반 구현임을 출처 설명에 적고, 공식 API 사용의 근거에서 제외한다. 고용24의 출처 표시·원문 이동 요건과 가공 허용 범위도 이용 승인 시 확인한다.

## 조사·검증 기록

- 설계 문서 및 `AGENTS.md`를 읽고 대상 행을 대조했다. `docs/harness/progress.md`는 조사 시작 시 존재하지 않아 읽지 못했다.
- `web` 검색/열람과 인증 없는 Python 표준 라이브러리 HTTP GET으로 공개 안내 페이지를 확인했다. 상세 탭 URL은 목록 HTML의 `fn_tabChange` 인자에서 얻었다. web 도구가 상세 URL 열람에 실패하여 동일 공식 페이지를 Python으로 직접 확인했으며, 실제 API 엔드포인트는 호출하지 않았다.
- 도구 실패: `python` 실행 파일 없음(exit 127), `python3`의 bs4 미설치(exit 1). 패키지 설치 없이 Python 표준 라이브러리로 재시도해 공식 상세 명세 열람에 성공했다. `selectOpenApiIntroPost.do` GET은 405였고 정식 공개 `selectOpenApiIntro.do`로 확인했다.
- 결과 파일에 대해 행 수·4열 표 형식·판정 수·필수 항목을 정적 확인했다. 기능 코드 변경이 없어 기능 테스트 작성·실행 대상은 없다. 설계 원문·다른 파일은 변경하지 않았다.
