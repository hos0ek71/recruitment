1. 이 저장소는 **네이버 공식 쇼핑 검색 API + 제조사 RSS/HTML 감시 + 다나와 HTML·화면용 AJAX 수집 + 저장된 시드/수동 입력**을 혼합한다.
2. “크롤링이 아니다”는 네이버 API와 시드 입력에는 맞지만, 제조사 HTML 감시와 다나와 수집에는 맞지 않는다.
3. 신제품은 제조사 게시글 분류 → 네이버 상품 후보 → 관리자 승인 → INACTIVE 자산 → 별도 ACTIVE 전환으로 연결된다.
4. RSS 데모는 자체 생성 샘플이며, 등록된 실제 제조사 9곳은 뉴스 HTML 주소다; Atom·sitemap 전용 파서는 확인되지 않았다.
5. 실패·중복·내부 품질을 기록하지만 외부 신제품 전수 수집을 증명하지 않는다; 페이지·검색 상한과 수동 검토 때문에 누락 가능성이 있다.

## 5. 공채 모아보기와의 관계 및 검증 기록

차용 가능한 설계는 공식 API의 별도 어댑터, 발견 게시글과 카탈로그 후보의 분리, 원천별 상태·변경 식별자, 검토 잠금, 사람 승인과 최종 공개의 분리다. 반면 제조사 HTML 감시·다나와 AJAX는 현재 공채 모아보기의 채용 사이트 스크래핑/브라우저 자동화 금지와 양립하는 대체 수집 경로가 아니다. 기존 기업 원천 20곳 조사(관심 기업 공개 피드 0/20 확인) 결과를 뒤집는 새 채용 원천을 확보한 조사도 아니다.

- 변경: `docs/research/05-dazzajo-data-intake.md` 신규 한 파일. 기능 코드·의존성·기존 문서·커밋 변경 없음.
- 조사 검증: 지정 Java 파일 9개와 스케줄러들, 관련 Flyway·application.yml·환경 예제·Compose·README·AGENTS·API 계약·가격 추이 감사 보고서를 정적 열람했다. 외부 수집 사이트/LLM에 실제 호출하지 않았다.
- 기능 구현이 없어 TDD 실패/통과 기록은 해당 없음. `make check`는 실행했으나 종료 코드 2: `docker compose up -d --wait db`가 Docker 데몬(`~/.docker/run/docker.sock`) 연결 실패로 중단되었다. 백엔드·웹 테스트는 시작되지 않았고 통과로 보고하지 않는다. 문서 근거 링크의 파일 존재·줄 범위와 필수 표/요약 형식은 별도 정적 검사했다.
- 남은 문제: 운영 활성화 여부, 실제 RSS 등록 상태, 최신 소스 응답·약관/개별 허락, 실제 누락률은 확인 못 함. 필요하면 운영자가 비밀값을 제거한 소스 목록·잡 이력·독립 제품 목록을 대조해야 한다.
