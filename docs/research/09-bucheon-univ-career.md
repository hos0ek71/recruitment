## 조사 범위와 확인 방법

학교 안내·FAQ·JOB4U의 서로 다른 메뉴 첫 페이지를 소량 열람했다. 채용 목록의 다음 페이지·마지막 페이지 링크는 열지 않았고, 검색 조건을 바꾸어 반복 요청하지 않았다. 학과 공고는 공식 검색 결과와 공개 상세의 출처 표시를 근거로 삼았으며 아래에는 제목 예시를 2건만 적었다. 로그인·가입·문의 발송·API 호출·포털 공고 상세 방문·수집 프로그램 구현은 하지 않았다.

웹 열람 도구가 JOB4U에서 `Internal Error`를 반환해, 동일한 공식 주소를 일반 HTTP GET으로 확인했다. `http://job4u.bc.ac.kr`은 HTTPS로 이동한 뒤 HTTP 200을 반환했고, 채용·달력·뉴스레터·FAQ도 비인증 요청으로 HTTP 200과 본문을 반환했다. 이는 서버가 보낸 공개 HTML의 확인이며, iframe 내부의 실제 표시 성공이나 로그인 후 기능까지 검증한 결과는 아니다. SELP는 웹 열람 오류 및 별도 GET 시간 초과로 현재 화면을 확인 못 함이다. [S3~S8·S10·S13, 확인 2026-10-19]

## 공고 출처와 학교 전용 규모를 어디까지 말할 수 있나

**학교 직접 접수·인재추천은 확인했다.** JOB4U 기업회원 FAQ는 기업의 공고 등록 후 담당자가 승인하며, 구인의뢰 확인 → 기업 담당자 통화 → 학과·컨설턴트 공지 → 인재추천으로 진행한다고 설명한다. 기업회원 가입이 어렵다면 유선 의뢰도 가능하다. 따라서 학교 접수 공고라는 실질적 경로는 있으나, 이 설명만으로 일반·추천탭 전건의 원천이나 학교 독점 여부를 확정할 수 없다. [S8, 확인 2026-10-19]

**학교 전용 규모의 대체 지표는 추천탭 표시 1,024건이다.** 이는 조회 시점의 게시판 총수이며 현재 모집 중인 공고 수·연간 신규 수·협약기업 수·학교 독점 수가 아니다. 첫 페이지에도 확인일 이전에 마감된 항목이 있어 현재 유효 수치로 사용할 수 없다. 일반채용 1,067건과 추천채용 1,024건의 중복 여부도 확인 못 함이므로 더하지 않는다. 학교 독점·협약기업·신입 IT 공고의 실제 규모는 **확인 못 함**이다. [S5·S6, 확인 2026-10-19]

**제목 수준의 예시 2건**:

- 정보통신과 「네트워크 인프라 운영 엔지니어 및 개발자 채용공고」(2026-07-09): 본문에 잡코리아를 정보 출처로 명시한다. 학교 경로에서 관련 IT 공고를 발견할 수 있다는 사례이며, 현재 지원 가능 공고로 제안하는 것은 아니다. [S9, 확인 2026-10-19]
- 항공서비스과 「호텔관광서비스 2026학년 이랜드파크 서비스인턴 30기 채용」(2026-07-09): 학과 추천 시 서류전형 면제 및 지도교수 문의 안내가 있다. 학교 추천의 추가 효용 사례지만, IT 직무나 학교 독점 공고라는 증거는 아니다. [S16, 확인 2026-10-19]

**연동 기술·공급업체는 구분해야 한다.** 잡코리아 **달력 iframe**은 확인했으나 잡코리아·사람인 **채용 API**의 학교 계약·동기화 주기·저장 범위는 확인 못 함이다. 고용24는 메뉴만 확인했고 실제 공고 행은 확인 못 했다. 잡링크 등 외부 채용정보 공급업체·플랫폼 솔루션 회사의 운영 표기 역시 확인 못 함이다. [S3~S6·S8·S11·S12, 확인 2026-10-19]

## 학교 경로로 잡코리아 공고를 받을 수 있나

**판정: 부분.** 사용자가 학교 공개 웹사이트에서 잡코리아 공채달력을 열람하고, 학과가 선별해 안내한 잡코리아 출처 공고를 보는 경로는 확인했다. 반면 사용자의 서비스로 공고 데이터를 자동 수신하는 RSS·메일링·학교 제공 API와 저장·정규화·AI 평가 허용 범위는 **확인 못 함**이다. 공개 열람을 자동 수집 허락으로 확대하지 않는다. [S4·S9·S11, 확인 2026-10-19; 연구자 판정]

잡코리아 공식 안내는 학교·공공기관 우선 제공과 사이트 단위 신청·담당자 승인·IP 등록을 설명한다. 학교의 학생이라는 사실만으로 학교용 API 호출 링크를 개인 프로젝트에서 사용할 수 있다고 볼 근거는 없다. 부천대가 해당 API를 계약했다는 증거도 확보하지 못했다. [S11, 확인 2026-10-19]

따라서 현재 실행 가능한 행동은 **공식 공개 목록·달력·뉴스레터의 사용자 열람과 담당 컨설턴트 문의**다. 자동 입력 경로는 학교가 제공 가능한 공식 피드와 사용 조건을 회신한 뒤 판단한다. 완전성 검증에는 최소한 피드 대상 범위, 고유 공고 ID, 총수·페이지/보관창, 정정·삭제·마감 반영 방식이 필요하다. 이는 이번에 확인된 기능이 아니라 **학교에 확인할 요구사항**이다. [S4~S8·S11, 확인 2026-10-19; 프로젝트 적용 판단]
